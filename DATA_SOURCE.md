# Raw data provenance

Eppink, Florian V., Matthew Winden, Will C. C. Wright, and Suzie Greenhalgh (2016). "Non-Market Values in a Cost-Benefit World: Evidence from a Choice Experiment." PLOS ONE 11(10), e0165365. https://doi.org/10.1371/journal.pone.0165365

The authors provide S1 Table, "Choice experiment responses," as a Stata data file. Original direct download URL: https://journals.plos.org/plosone/article/file?id=10.1371/journal.pone.0165365.s001&type=supplementary

For this individual repository, the supplementary file was downloaded again on November 8, 2026 (America/Los_Angeles). It is byte-identical to the team copy. The date of the team's original download is not documented and is not claimed here. The file is stored unchanged at `data/raw/S1Table.DTA` (5,276,294 bytes).
